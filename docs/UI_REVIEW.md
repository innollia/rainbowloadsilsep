## 발견 (심각한 순)

### 1. [높음] 좁은 폭(390px)에서 화면이 가로로 넘친다
- 화면: 에셋 작업실, `r_a9_390.png`
- 무엇: 오른쪽 끝 `음악 작업실로` 단추가 화면 밖으로 밀려 안 보이고, 샘플 안내 줄의 `나머지 만들기`와 타일 둘째 열이 잘린다. `body { overflow:hidden }`이라 스크롤로도 못 닿는다. 휴대폰에서는 음악 화면으로 돌아갈 길이 없다.
- 왜: 7번. 길게 누르기 등 터치 조작을 이미 지원하는데 폭이 받쳐 주지 않는다.
- 고칠 안(새 UI 없음): 넘침 원인 요소에 `min-width:0`/`flex-wrap`을 준다. 샘플 안내 줄(`.importHint` 옆 승인 줄)은 600px 이하에서 문장 아래로 단추를 줄바꿈, `.grid`는 `minmax(min(150px,100%),1fr)`, `.tile.wide`는 1열일 때 `span 1`. 머리줄은 `#progress`를 600px 이하에서 숨겨 단추 넷이 들어가게 한다.

### 2. [높음] 900px 이하에서 분류·상태 목록이 사라지고 대체 경로가 없다
- 화면: 에셋 작업실, `r_a8_800.png`
- 무엇: `@media (max-width:900px) { #side { display:none } }`. 분류 필터, 상태 필터(대기·확인 필요), 분류 추가(아이콘)가 함께 없어진다. 800px 노트북 반창에서도 분류 추가가 불가능하다.
- 왜: 7번, 기획서 §3 보드(왼쪽 분류·상태 필터).
- 고칠 안(새 UI 없음): 숨기지 말고 폭만 줄인다. 900px 이하에서 `#side`를 아이콘 레일(분류 색 점 + 개수, 너비 56px)로 바꾸고 이름은 `title`/`aria-label`로 둔다. 분류 추가 아이콘은 그대로 남는다.

### 3. [중간] 한국어 줄바꿈이 낱자 단위로 끊긴다
- 화면: 두 화면 모두, `r_a0_first.png`("여 / 러 안을"), `r_a9_390.png`("들어 보 / 고")
- 무엇: 두 `style.css` 어디에도 `word-break: keep-all`이 없다.
- 왜: 11번(단어 단위 줄바꿈).

### 4. [중간] 한글 입력 중 Enter 처리가 빠졌다
- 화면: 에셋 작업실 코드(`asset_studio/app.js` 855행, 1102행)
- 무엇: F2 이름 바꾸기 입력이 `e.key === 'Enter'`만 보고 끝낸다. 조합 중인 마지막 글자가 빠지거나 중복될 수 있다(예: "레벨 업" 입력 후 Enter). 아래 입력창도 `form submit` 뒤 `value=''`로 비우므로 조합 끝 글자가 빈 칸에 다시 남을 수 있다. 음악 화면은 `!e.isComposing`을 이미 검사한다(`app.js` 1051행).
  ```js
  input.onkeydown = (e) => { e.stopPropagation(); if (e.key === 'Enter') finish(true); ... };
  ```
- 왜: 11번(IME 조합 중 Enter).
- 고칠 안: 855행 조건을 `e.key === 'Enter' && !e.isComposing`으로. 아래 입력창은 `#ask`에 `keydown`에서 `e.isComposing`이면 `preventDefault` 하도록 음악 화면과 같은 방식으로. 실제 한글 입력으로 확인한다.

### 5. [중간] 문구가 규칙 11과 두 화면 사이에서 어긋난다
- 화면: 두 화면, `r_a5_spec.png`, 코드(`i18n.js`, `asset_studio/app.js`)
- 무엇:

  - 명세 창 탭 이름이 `프롬프트 보내기`인데 실제로는 복사만 한다. 같은 창은 "음악 작업을 하던 에이전트에게 붙여 넣으세요", 사용법은 "게임 기획서를 가진 AI에게 보내고"라고 대상이 다르다.
