# 음악 생성 모델 가성비 정리 (MODEL_VALUE)

기존 대결 기록(bakeoff/results)만 다시 계산했다. 새 생성·채점 호출은 없다. 다시 계산: `python bakeoff/value.py` (표만 출력, 결론은 손으로 쓴 것).

- 원가: 공개 사이트가 낼 API 요금 기준. OpenRouter 모델은 기록된 cost(캐시 할인 반영)를 그대로 썼다. 구독 CLI(agy, codex)는 기록된 토큰에 OpenRouter 같은 모델 단가를 곱했다: google/gemini-3.8-flash 입력 $0.825/M·출력 $4.125/M·캐시 $0.0825/M, openai/gpt-5.6-luna $0.20/$1.20/$0.02, openai/gpt-5.6-terra $2/$12/$0.20.
- "작업당 원가" = 성공·실패 작업 평균. "성공 곡당 원가" = 실패 작업 비용까지 합친 총액 / 성공 곡 수. 하네스 장애(우리 쪽 고장)로 분류된 작업과 그 재시도 파일은 뺐다.
- 점수: report2.md와 같은 방식(심판 3개 첫 채점 평균, 95% 부트스트랩). 사람 블라인드는 listen.sqlite의 쌍대 비교 첫 선택 승률.
- 파레토 앞줄: 성공 곡당 원가가 같거나 더 싸면서 점수가 같거나 높은 다른 모델이 없는 모델.

단가 출처: OpenRouter 공개 모델 목록(live). CLI 입력 토큰 중앙값이 OpenRouter 호출 중앙값(6321)보다 큰 몫: agy 9798, codex 17039 토큰/호출.

## 결론

**최고 성능(B): claude-opus-5.5로 정한다(사용자 결정, 상위 모델 추가 실험은 하지 않음).**

| 심판 합산 | 79.3 (77~81), 12개 중 1위 / z 0.30 (0.07~0.52) |

| 특징 | 편집 지시를 지키면서 크게 바꿈(7번 베이스 변화 66%, 다른 트랙 0%), 곡당 소리 6.4종, 작업 90초 |

**가성비(A) 후보: deepseek-v4.1-flash가 1순위, claude-haiku-5.5가 2순위.**

- deepseek-v4.1-flash: 곡당 $0.007(Opus의 약 1/17), 점수 77.9로 Opus와 차이 -1.4(95% 범위 -4~+2, 0을 포함). 100% 성공. 파레토 앞줄.
- claude-haiku-5.5: 곡당 $0.004로 가장 싼 유료 모델, 100% 성공, 점수 75.9(Opus와 차이 -3.4, 범위 -6~-0으로 유의하게 낮음). 파레토 앞줄.
- nemotron free는 원가 0이라 앞줄이지만 점수가 가장 낮고 무료 등급 속도 제한이 있다. 유료판으로 보면 앞줄에서 빠진다.
- glm-5.3($0.010, 76.8)은 앞줄 바로 뒤, 가장 빠르다.
- 구독 CLI 모델(gemini-3.8-flash, gpt-5.6-terra, luna)은 API 요금으로 내면 싸지 않다. gemini는 생각 토큰 때문에 곡당 $0.26로 가장 비싸다.

**불확실한 점**

- 심판 점수 차이가 작다. Opus를 뺀 상위권(deepseek, gemini, sonnet, terra, kimi)은 95% 범위가 대부분 겹친다. 심판 간 상관도 0.47~0.67이다.
- 사람 블라인드는 투표자 3명·첫 선택 63개, 결승 5개 모델뿐이다. 사람 쪽에서는 terra·gemini·sonnet(55~56%)이 Opus(43%)·deepseek(47%)보다 높아 심판 순위와 어긋난다.
- CLI 환산 원가는 CLI 자체 시스템 프롬프트·도구 설명이 입력에 섞여 실제 API 직접 호출보다 높게 나온다(호출당 입력이 OpenRouter 중앙값보다 agy 약 9.8천, codex 약 1.7만 토큰 많음). "CLI 몫 뺀 추정" 열은 그 차이를 뺀 대략값이다(terra $0.058, luna $0.007, gemini $0.213). gemini는 출력(생각) 토큰이 원가 대부분이라 API에서 생각 예산을 줄이면 달라질 수 있다. agy의 output_tokens가 생각 토큰을 포함한다고 보고 계산했다.
- 반복 수가 모델마다 다르다(sonnet·glm 2회, kimi 1회). sonnet은 심판 점수가 8곡, kimi는 2곡만 있다.
- 단가는 2026-11-08 OpenRouter 목록 기준이다. 시간대별 할인(minimax 등)이나 배치 요금은 넣지 않았다.
